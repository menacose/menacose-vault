## Organisation

01_Governance: For the governance topics of our chapters: By-Laws, Vision, Mission, Strategy, etc.

02_Inbox: For any new item that needs to be discussed/processed by us like an inquiry to reply to or a proposal to study and decide on it. Consider it like our mailbox / incoming requests filtering space.

03_Meetings: For notes about any meetings we have whether board meetings or other meeting.

04_Projects: Project notes and the shared Work Overview and Action Register, as described in [[Projects and Meetings Guide]].

05_ to 12_: Working areas for Working Groups, SE Education, Communications, Finance, Secretary, Programs, President and VP. Start at [[Area Directory]].

90_Attachments: For holding all attachments: images, screenshots, and PDFs.

99_Templates: For templates. To have a database of all of our asset. We will use light templates including metadata like: Date of creation. status, tags/hashtags, etc.

## Processes

1. You select the relevant space to create your note.
2. Check if there is a suitable template to use, if not create a new one following the pattern of others. If your note content or metadata needs will not be recurring, DON'T create a template.
3. Try to use backlinks and tags where suitable/necessary to have connected/linked notes.
4. To draw something, select where you would like to draw it, right-click and select "New drawing".
5. You can use the toolbar in the top for formatting like in Word.
6. If you want to add/take a slot of the bi-weekly Qahwa or Expert Talk, go to the Advanced Agenda to add your desired event.
7. Don't install or use additional community plugins.

## Start Working

1. Check [[Work Overview]] for projects and recurring activities.
2. Keep specific next steps in [[Action Register]].
3. Open [[MENACOSE People]] and [[Area Directory]] for people and working areas.
4. Use [[Meeting Agenda and MoMs]] for each new weekly meeting.
5. Keep dates and commitments recorded in old minutes; update current status in the registers.

## Images And Attachments

Paste or drop images into a note as usual. Custom Attachment Location routes new image attachments to `90_Attachments/90.01_Images/<ISO year>/W<week>/`; weeks start on Monday. For example, an image attached on 25 October 2026 goes to `2026/W43/`.

Existing pasted images and screenshots use the date in their filenames. New attachments use the date they are added. Names are preserved, with a suffix if needed to avoid collisions. Other file types go to `90_Attachments`.

Enable **Custom Attachment Location** and its required **Advanced Rename and Delete Handler** companion in Community plugins, then reload Obsidian. The folder rule is configured under Custom Attachment Location → Location for new attachments. Core fallback: Files and links → Default location for new attachments → `90_Attachments`.

Image conversion, deduplication and automatic deletion are disabled. Keep links intact when moving attachments.
